## Definition
- Used to assign a [[Sources of Values|Value]] to a [[Variable]].
### Examples
```java
x = 10; // assignment to a literal
x = y; // assignment to another variable
brick = new GRect(25,30); // assignment to a new instance
x = 6 * 7; // assignment to an expression
word = getWord(); // assignment to a method's return
```
