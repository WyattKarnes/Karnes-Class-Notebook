## Definition
- Software that communicates with the hardware and allows other programs to run. 
- It is comprised of system software, or the fundamental files your computer needs to boot up and function. 
- Every desktop computer, tablet, and smartphone includes and operating system that provides basic functionality for the device.
- Common desktop operating systems include Windows, OS X, and Linux.
