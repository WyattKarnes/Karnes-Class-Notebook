---
title: Markup Exercises
---
Interactive versions of the code markup worksheets. Each one gives you an unfamiliar Java program and asks you to:

- **Name It:** pick the vocabulary term for a highlighted piece of code.
- **Find It:** click the line that matches a description.
- **Mark It Up:** circle, box, underline or star pieces of code.

When you finish, open the **Score** tab and screenshot it for Canvas.

## Exercises

- [[Arcade Markup|Arcade Code Markup]]: methods, parameters, loops, and if / else if
