## Notes and Info
- A variable defined as part of the signature of a [[Method]], inside of its parenthesis.
- Act as input definitions for the method.
### Syntax
- ([[Data Types.canvas|Data Type]] [[Identifier]])
### Examples
```java
// pi is a parameter
void myMethod(double pi){
	// code
}

// b and s are parameters
void myMethod(boolean b, String s){
	// code
}
```
