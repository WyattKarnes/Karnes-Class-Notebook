## Definition
- Defines the output type of a [[Method]].
- Can be any [[Data Types.canvas|Data Type]] OR void.
- Void means that the method does not return anything. ^4620f3
### Examples
```java
// a method that returns nothing
void myMethod(){
	// code
}

// a method that returns a String
String myOtherMethod(int x){
	// code
}

```
