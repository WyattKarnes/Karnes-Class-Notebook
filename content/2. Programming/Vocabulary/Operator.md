## Definition
- Symbols that tell a computer to perform a specific action.
- Usually paired with two, sometimes one, [[Operand|Operands]]. An operator that works with only one operand is called a *unary* operator, and an operator that works on two is a *binary* operator. There is also one *ternary* operator.
### Categories
#### Arithmetic
```java
+ // add
- // sub
* // multiply
/ // divide
% // mod
```
#### Assignment
```java
= // assign
+=
-=
*=
/=
%=
++ // increment
-- // decrement
```
#### Conditional/Comparison
```java
== // equal to
!= // not equal to
> // greater than
< // less than
>= // greater than or equal to
<= // less than or equal to
? : // ternary (not technically in category)  
```
#### Logical
```java
&& // AND
|| // OR
! // NOT
```
