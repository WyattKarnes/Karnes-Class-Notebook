## Definition
- The first time a [[Sources of Values|Value]] is [[Assignment Statement|Assigned]] to a [[Variable]].
- Primitive types have default values, so failure to initialize will not necessarily cause errors.
- Reference types **DO NOT** have default values, so failure to initialize will cause a [[Null Pointer Exception]].
