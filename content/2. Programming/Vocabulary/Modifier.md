## Definition
- Affects the accessibility or function of the things they are attached to.
---
### Access Modifiers
- public ^aba5aa
	- Has read/write access to all classes.
- private
	- Has read/write access only in the class it was declared in.
- protected
	- Has read/write access in the class it was declared in, and its children.
- default (package private)
	- Public within its package, private outside its package.
### Non-Access Modifiers

^2c2980

- final ^1d2b42
	- Marks a field as constant
- static ^5e8c8e
	- Marks something as class level
