# Karnes Class Notebook

Quartz 4 site (built from an Obsidian vault; the vault root is this repo) for Mr. Karnes' high school CS classes. Published notes live in `content/`. Students use MacBooks with Safari and Chrome.

- Preview locally: `npx quartz build --serve` (http://localhost:8080). Publishing is `npx quartz sync`; only do that when asked.
- Don't edit student-facing notes in `content/` unless the task is about them.

## Code markup exercises

Interactive vocabulary exercises live in `content/2. Programming/Markup Exercises/`. To make a new one (e.g. "make a new markup exercise from this code"), first read
`content/2. Programming/Markup Exercises/markup-engine/AUTHORING.md`. It has the data schema, a full example, and a step-by-step checklist.
